# DSA Practice

A collection of Data Structures & Algorithms problems solved and organized by pattern, with explanations and notes for each solution.

## Structure

Problems are organized into folders by pattern/topic. Each folder contains the problem statement, my approach, and the solution code.

## Patterns Covered

- Two Pointers
- Slow & Fast Pointers
- Sliding Window
- Hashmap
- Prefix Sum
- Kadane's Algorithm
- Merge Intervals
- Linked List Reversal
- Stack

## How to Navigate

Each problem folder includes:
- Problem explanation
- Approach/intuition
- Solution code
- LeetCode problem ID
